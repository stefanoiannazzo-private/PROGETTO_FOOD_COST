# Food Cost

Applicazione web di COMETOWEB per ristoranti, gastronomie, macellerie, pasticcerie e laboratori alimentari: calcola il costo di produzione delle preparazioni (ingredienti, energia, manodopera) per lotto, per porzione e per chilogrammo, con ricette annidate e snapshot storici.

**Stato:** fase 1 di 7 completata (piano e architettura). Il codice applicativo arriva dalla fase 2.

- Piano, architettura, formule e decisioni: [`docs/PIANO.md`](docs/PIANO.md)

Stack: Laravel 12 (API) · Next.js + React + TypeScript · MySQL 8.4 · Redis.

Le istruzioni di installazione e avvio verranno aggiunte con il codice.
